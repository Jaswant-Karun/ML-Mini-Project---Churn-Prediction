# Customer Churn Prediction Project

This project predicts whether a telecom customer will churn (leave service) or not churn (stay).

## Problem Statement

Customer churn prediction is a binary classification task:

- 1 = Churn
- 0 = Stay

## Dataset

Recommended dataset: Telco Customer Churn

- Kaggle URL: [Telco Customer Churn](https://www.kaggle.com/blastchar/telco-customer-churn)
- Download the CSV and place it at:
  - `data/Telco-Customer-Churn.csv`

## Setup

1. Create and activate a virtual environment
2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Train and Compare Models

This script trains Logistic Regression, Decision Tree, and Random Forest, then selects the best model by F1 score.

```bash
python src/train_model.py
```

Outputs:

- `model/churn_model.pkl` (best model pipeline)
- `model/metrics.json` (all model results)

## Evaluate Saved Model

```bash
python src/evaluate.py
```

## Run Streamlit App (Optional Bonus)

```bash
streamlit run app/app.py
```

Upload a CSV file and get predicted labels (Stay/Churn).

## Run Web Frontend + Backend (Recommended)

1. Train model first:

```bash
python src/train_model.py
```

1. Start FastAPI server:

```bash
uvicorn web.backend.main:app --reload
```

1. Open in browser:

```text
http://127.0.0.1:8000
```

## Run Frontend and Backend Separately

If you want two terminals, use this setup:

1. Backend terminal:

```bash
uvicorn web.backend.main:app --reload
```

1. Frontend terminal:

```bash
cd web/frontend
python -m http.server 5500
```

1. Open the frontend in your browser:

```text
http://127.0.0.1:5500
```

The frontend is configured to call the backend at `http://127.0.0.1:8000`.

## Supabase Setup (Prediction History)

Create a table in Supabase SQL editor:

```sql
create table if not exists prediction_logs (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  prediction int,
  label text,
  churn_probability double precision,
  features jsonb
);
```

Set environment variables before running backend:

```powershell
$env:SUPABASE_URL="https://YOUR_PROJECT.supabase.co"
$env:SUPABASE_KEY="YOUR_ANON_OR_SERVICE_ROLE_KEY"
$env:SUPABASE_TABLE="prediction_logs"
```

If Supabase variables are not set, the app still runs and predictions work. Only history logging is disabled.
